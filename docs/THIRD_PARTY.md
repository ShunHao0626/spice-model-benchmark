# Third-party model sources

This repository retains license and notice files alongside third-party source code. The repository-level MIT license applies only to the benchmark code and does not replace these terms.

| Directory | Source and license |
| --- | --- |
| `models/FreePDK45/` | FreePDK45 model files; Apache 2.0 notice in `APACHE-LICENSE-2.0.txt` |
| `third_party/BSIM-BULK/` | UC Berkeley BSIM-BULK; conditions in `LICENSE` |
| `third_party/BSIM-CMG/` | UC Berkeley BSIM-CMG; `LICENSE.txt` and `NOTICE.txt` |
| `third_party/BSIM-SOI/` | UC Berkeley BSIM-SOI; source header and nested BSIM4 license |
| `third_party/BSIM3/` | UC Berkeley BSIM3; `B3TERMS_OF_USE` |

The BSIM-IMG beta release was not copied: its `BETA_LICENSE.txt` marks the work confidential and prohibits redistribution without prior written consent. Large PDK packages and paper PDFs from the source folders were also not copied. Their original local copies remain under `SJTU/` or `spice_model_benchmark_old/`. Check upstream terms before obtaining or redistributing them.
